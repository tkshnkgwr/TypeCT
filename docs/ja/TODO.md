# TypeCT 今後の機能拡張ロードマップ (TODO)

本書は、`TypeCT` の今後の機能拡張予定およびロードマップをまとめたものです。

---

## 📌 今後の実装候補

| 優先度 | 項目名                        | 概要                                                         |
| :----- | :---------------------------- | :----------------------------------------------------------- |
| 高     | Windows スタートアップ登録    | 設定ダイアログからワンクリックで Windows 起動時の自動実行を登録 |
| 高     | CSV / TSV エクスポート機能    | 日別・月別の打鍵記録をスプレッドシート用に書き出す機能       |
| 中     | ダーク / ライトテーマ切替     | UI のカラーテーマを OS 設定追従または手動切り替え可能にする  |
| 中     | 目標打鍵数達成トースト通知    | 1日の目標打鍵数（例: 10,000打）に達した際にトーストでお祝い  |
| 中     | マウス移動距離の計測          | マウスカーソルの移動距離（メートル/キロメートル）の換算集計  |
| 低     | ヒートマップキーボード表示    | キーボード配列画像上に打鍵頻度をヒートマップで視覚表示       |
| 低     | クラウド同期 (暗号化バックアップ) | 複数PC間で打鍵数を合算できるオプショナルなE2E暗号化同期     |
