## 📌 新規実装候補ロードマップ

| 優先度 | 機能項目名                        | カテゴリ     | 概要                                                         |
| :----- | :-------------------------------- | :----------- | :----------------------------------------------------------- |
| 高     | リアルタイムタイピング速度 (KPM)  | 分析・計測   | 直近1分間の打鍵速度（KPM: 打/分）のリアルタイム表示とピーク値記録 |
| 高     | カレンダー草生えアクティビティ    | 履歴・可視化 | GitHub スタイルの年間・月間カレンダーグリッドと日別振り返り  |
| 高     | 自動世代バックアップ保護          | 堅牢性       | 日付変更時に `backups/` へ `typect.json` を自動世代退避      |
| 中     | アプリ別（プロセス別）打鍵集計    | 生産性分析   | VS Code、ブラウザ等のフォアグラウンドアプリ別打鍵比率の内訳  |
| 中     | ポモドーロ・長風呂休憩リマインダー| ヘルスケア   | 連続打鍵時間や打鍵数に応じた腱鞘炎・VDT予防の休憩推奨通知    |
| 中     | 計測一時停止ホットキー            | プライバシー | ゲーム中や機密入力時にワンキー (`Ctrl+Shift+P`) で計測一時停止 |
| 中     | 週報・月報レポート画像エクスポート| シェア・出力 | 1週間の成果を美しいカード画像 (PNG) に出力してクリップボード保存 |
| 低     | タイピング音・打鍵効果音          | 体験・演出   | レトロなタイプライターや青軸メカニカル音のエフェクト再生     |
| 低     | クラウド同期 (暗号化バックアップ) | 同期・連携   | 複数PC間で打鍵数を合算できるオプショナルなE2E暗号化同期      |
