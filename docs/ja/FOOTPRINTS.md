# TypeCT 開発経緯・足跡 (FOOTPRINTS)

本書は、かつての Windows で広く愛用されていた名作フリーソフト「タイプ数カウンター (typect)」から、現代の Rust 版「TypeCT」へと至る歩みと開発背景についての記録です。

---

## 1. 原点: Borland C++ 5.5 時代の「タイプ数カウンター」

1990年代後半から2000年代の Windows 95/98/2000/XP 時代、PC 作業のモチベーション向上や腱鞘炎予防、日々の仕事量の可視化として、数多くのプログラマーやライターに愛用されていたフリーソフトが「タイプ数カウンター (typect.exe)」でした。

Borland C++ 5.5 によって作成されたそのソフトは、極限まで無駄を削ぎ落としたサイズと軽快さ、タスクトレイに常駐して何気なく打鍵数を数えてくれる頼もしい相棒でした。
データはシンプルな固定長バイナリ (`data` / `data2`) に4バイト整数のリトルエンディアンで記録され、長年にわたって数百万打鍵、数千万打鍵の歴史を刻み続けてきました。

---

## 2. 刷新の動機: Windows 11 時代の課題

しかし、時代は流れ Windows 11 (64bit) の時代へ。
旧来の 32bit アプリケーションは互換モード等で動くものの、
- 高DPI環境における文字の滲みやレイアウト崩れ
- 文字コードの差異や最新OSでのタスクトレイ挙動の変化
- モダンなグラフ可視化やJSON等のオープンフォーマットへの対応の難しさ
など、現代的な環境で常用し続けるにはいくつかのハードルが生じていました。

「あの軽快で信頼できるタイプ数カウンターを、現代の技術で蘇らせたい」
「過去何年間も刻んできた `data` の累計カウントを捨てることなく、そのまま引き継ぎたい」

その強い想いから、新世代の「TypeCT」開発プロジェクトが始動しました。

---

## 3. Rust + egui による新世代の実装

新たな TypeCT には、現代のシステムプログラミング言語の最高峰である **Rust** を選択しました。

- **メモリ安全性と堅牢性**: クラッシュやデータ破壊の心配がない安心の常駐性。
- **低遅延フック**: `rdev` を用いた高速な入力捕捉により、ゲームやタイピング作業中にも一切遅延を与えない。
- **即時モード GUI (egui)**: 高速・軽量で高DPIにも完全対応した美しいダッシュボードと時間帯別グラフ。
- **過去データの完全継承**: 旧バイナリフォーマットを徹底解析し、初回起動時に累計記録をそのまま自動インポートする後方互換設計。

過去の名作への最大限のリスペクトを込めて、TypeCT はこれからの Windows 11 時代を再び共に歩んでいきます。
