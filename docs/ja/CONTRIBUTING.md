# TypeCT コントリビューションガイド (CONTRIBUTING)

`TypeCT` への貢献をご検討いただきありがとうございます！
本プロジェクトへの参加・機能提案・バグ報告にあたってのガイドラインです。

---

## 1. 開発への参加手順

1. 本リポジトリをフォークします。
2. 機能追加または修正用のブランチを作成します (`git checkout -b feature/awesome-feature` 等)。
3. 変更を実装し、テストを追加・更新します。
4. 以下の検証コマンドを実行し、エラーや警告が一切ないことを確認します。
   ```powershell
   cargo fmt --check
   cargo clippy --all-targets -- -D warnings
   cargo test
   ```
5. 規約に沿ったコミットメッセージでコミットし、プッシュしてプルリクエスト (PR) を作成してください。

---

## 2. コーディング規約

- **Rust の慣例**: `cargo fmt` および `cargo clippy` の標準指針に厳格に従います。
- **RustDoc**: パブリックな構造体、メソッド、関数には必ず日本語による目的・引数・戻り値・使用例（Doc-test）を記述してください。
- **Markdown テーブルの垂直整列**: ドキュメント作成・編集時は、パイプ `|` とハイフン `-` を垂直に整列させてください。
- **プライバシー保護の厳守**: キーロガーとなるような変更（入力文字列の連結やバッファ蓄積、外部ネットワーク送信等）は一切受け入れられません。
