# TypeCT 詳細仕様書 (SPECIFICATION)

本書は、Rust + egui 製打鍵・マウスクリック数計測アプリケーション「TypeCT」の機能要件、データ仕様、UI仕様、セキュリティ要件についての詳細仕様書です。

---

## 1. システム概要

- **名称**: TypeCT (タイプ数カウンター)
- **バージョン**: 0.1.0
- **対象OS**: Windows 11 (64bitネイティブ対応) / Windows 10 (64bit)
- **開発言語**: Rust 2021 Edition
- **主要クレート**:
  - GUI: `eframe` 0.29, `egui` 0.29, `egui_plot` 0.29
  - 入力監視: `rdev` 0.5
  - シリアライズ: `serde` 1.0, `serde_json` 1.0
  - 日時: `chrono` 0.4
  - 二重起動防止: `single-instance` 0.3
  - タスクトレイ: `tray-icon` 0.19
  - Windows API: `windows-sys` 0.59

## 2. 機能要件

### 2.1 二重起動防止 (Single Instance)
- Windows Named Mutex (`TypeCT_Windows11_SingleInstance_App_Lock`) を使用して同一マシン内での二重起動を排他制御します。
- 既にインスタンスが起動している状態で別のプロセスが起動された場合、後から起動したプロセスは一切のウィンドウを出さずに静かに即時終了 (Exit code 0) します。

### 2.2 グローバル入力監視 & プライバシー保護
- `rdev::listen` を `std::thread::spawn` による独立スレッドで実行します。
- メインGUIスレッドへの通知は `std::sync::mpsc::channel` による非同期通信を採用し、タイピングやマウス操作に一切の入力遅延（ラグ）を与えません。
- **プライバシー保護原則**:
  - キーロガー機能は一切排除。
  - テキスト内容、単語、パスワード等の文字列は保持・保存しません。
  - 単一キー（`A`, `Enter`, `Ctrl` 等）またはマウスボタン（`左クリック`, `右クリック` 等）のカウンター加算のみを行います。

### 2.3 旧データ自動インポート
Borland C++ 5.5 製旧ソフト「タイプ数カウンター (typect.exe)」のデータファイルを検出して自動引き継ぎを行います。

#### 旧バイナリ構造 (`data`: 打鍵, `data2`: クリック)
先頭28バイトの固定長バイナリ（各4バイト・リトルエンディアン整数）:

| オフセット | 型  | 項目名            | 内容                                    |
| :--------- | :-- | :---------------- | :-------------------------------------- |
| `0x00`     | u32 | `days_recorded`   | 記録日数（通算日数）                    |
| `0x04`     | u32 | `last_year`       | 最終記録年（西暦）                      |
| `0x08`     | u32 | `last_month`      | 最終記録月 (1〜12)                      |
| `0x0C`     | u32 | `last_day`        | 最終記録日 (1〜31)                      |
| `0x10`     | u32 | `total_count`     | 累計トータルカウント                    |
| `0x14`     | u32 | `today_count`     | 本日のカウント                          |
| `0x18`     | u32 | `yesterday_count` | 昨日のカウント                          |

- `typect.exe` 起動時、同一ディレクトリに `data` または `data2` が存在し、かつ `typect.json` で未インポートの場合、上記ヘッダを解析して累計カウント・本日・昨日のカウント・記録日数を引き継ぎます。

### 2.4 日付ロールオーバー
- 日付変更（午前0時）を自動検知します。
- `last_date != 今日` となった時点で以下の処理を実行します:
  - `yesterday_keys = today_keys`
  - `yesterday_clicks = today_clicks`
  - `today_keys = 0`
  - `today_clicks = 0`
  - `hourly_keys = [0; 24]`
  - `days_recorded += 1`
  - `last_date = 今日`

### 2.5 タスクトレイ常駐 & 動的ツールチップ
- ウィンドウ最小化、または右上「✕」ボタン押下時にウィンドウを非表示化し、タスクトレイに格納。
- トレイアイコンの左クリックでウィンドウを復帰・再表示。
- トレイアイコンにマウスをホバーした際、ツールチップに現在の打鍵状況を動的に表示:
  ```text
  TypeCT - 今日: 6,183打 / 4,952クリック
  ```
- ツールチップ更新は CPU 負荷軽減のため最短 1 秒間隔で実施。

## 3. UI 画面構成

1. **ヘッダーパネル (`TopBottomPanel::top`)**:
   - アプリタイトル: `⌨ TypeCT (タイプ数カウンター)`
   - 操作ボタン:
     - `💾 保存`: 即座に JSON ファイルへ手動保存
     - `📥 トレイに格納`: ウィンドウを非表示にしてタスクトレイへ退避
     - `❌ 終了`: データを保存してアプリを完全終了
2. **中央メインパネル (`CentralPanel`)**:
   - **サマリーカード (4枚横並び)**:
     - 本日の打鍵数 & クリック数
     - 昨日の実績打鍵数 & クリック数
     - 累計トータル打鍵数 & クリック数
     - 記録日数 & 1日平均打鍵数
   - **直近24時間の時間帯別打鍵数グラフ**:
     - `egui_plot::BarChart` による 0時〜23時の棒グラフ
   - **主要キー別打鍵数ランキング**:
     - 上位12キーの打鍵回数およびプログレスバー表示
   - **インポートステータスバッジ**:
     - 旧データ引き継ぎ済みの場合に緑色のインジケーターを表示
3. **ステータスバー (`TopBottomPanel::bottom`)**:
   - 計測状態ステータスおよび JSON 保存先フルパスを表示

## 4. データ永続化仕様 (`typect.json`)

| フィールド名       | 型                    | 説明                                         |
| :----------------- | :-------------------- | :------------------------------------------- |
| `total_keys`       | `u64`                 | 累計総打鍵数                                 |
| `today_keys`       | `u64`                 | 本日の打鍵数                                 |
| `yesterday_keys`   | `u64`                 | 昨日の打鍵数                                 |
| `total_clicks`     | `u64`                 | 累計マウスクリック数                         |
| `today_clicks`     | `u64`                 | 本日のマウスクリック数                       |
| `yesterday_clicks` | `u64`                 | 昨日のマウスクリック数                       |
| `days_recorded`    | `u32`                 | 記録日数（通算日数）                         |
| `last_date`        | `String`              | 最終記録日付 (`YYYY-MM-DD`)                  |
| `hourly_keys`      | `[u32; 24]`           | 直近24時間の時間帯別打鍵数                   |
| `key_counts`       | `HashMap<String,u64>` | キー種別ごとの打鍵数マップ                   |
| `mouse_counts`     | `HashMap<String,u64>` | マウスボタン種別ごとのクリック数マップ       |
| `legacy_imported`  | `bool`                | 旧バージョンデータ引き継ぎ完了フラグ         |
