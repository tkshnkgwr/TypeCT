# TypeCT 詳細仕様書 (SPECIFICATION)

本書は、Rust + egui 製打鍵・マウスクリック数・マウス移動距離計測アプリケーション「TypeCT」の機能要件、データ仕様、UI仕様、セキュリティ要件についての詳細仕様書です。

---

## 1. システム概要

- **名称**: TypeCT (タイプ数カウンター)
- **バージョン**: 0.2.1
- **対象OS**: Windows 11 (64bitネイティブ対応) / Windows 10 (64bit)
- **開発言語**: Rust 2021 Edition
- **主要クレート**:
  - GUI: `eframe` 0.29, `egui` 0.29, `egui_plot` 0.29
  - 入力監視: `rdev` 0.5
  - シリアライズ: `serde` 1.0, `serde_json` 1.0
  - 日時: `chrono` 0.4
  - 二重起動防止: `single-instance` 0.3
  - タスクトレイ: `tray-icon` 0.19
  - Windows トースト通知: `notify-rust` 4.18
  - Windows レジストリ: `winreg` 0.52
  - Windows API: `windows-sys` 0.59

## 2. 機能要件

### 2.1 二重起動防止 (Single Instance)
- Windows Named Mutex (`TypeCT_Windows11_SingleInstance_App_Lock`) を使用して同一マシン内での二重起動を排他制御します。
- 既にインスタンスが起動している状態で別のプロセスが起動された場合、後から起動したプロセスは一切のウィンドウを出さずに静かに即時終了 (Exit code 0) します。

### 2.2 グローバル入力監視 & プライバシー保護
- `rdev::listen` を `std::thread::spawn` による独立スレッドで実行します。
- メインGUIスレッドへの通知は `std::sync::mpsc::channel` による非同期通信を採用し、タイピングやマウス操作に一切の入力遅延（ラグ）を与えません。
- **プライバシー保護原則**:
  - キーロガー機能は一切排除。
  - テキスト内容、単語、パスワード等の文字列は保持・保存しません。
  - 単一キー（`A`, `Enter`, `Ctrl` 等）またはマウスボタン（`左クリック`, `右クリック` 等）のカウンター加算のみを行います。

### 2.3 マウス移動距離の計測
- `rdev::EventType::MouseMove { x, y }` イベントを捕捉し、前回の座標からのユークリッド距離（ピクセル）を算出。
- 標準的な画面解像度（96 DPI: 1 inch = 25.4 mm）を基準として、1 px ≈ 0.0002645833 m の換算式で実測距離（メートル）を積算します。
- 累計移動距離、本日の移動距離、昨日の移動距離を記録・表示します。

### 2.4 キーボードヒートマップ表示
- QWERTY 配列（全6行）の視覚的なキーボードUIを提供。
- 最高打鍵数に対する比率に応じて、キーの背景色をヒートマップグラデーション（青 → シアン → 緑 → 黄 → 赤）で動的に色分け描画。
- マウスホバー時に打鍵回数と出現頻度比率を表示。

### 2.5 目標打鍵数達成トースト通知
- 1日の目標打鍵数（既定値: 10,000打）を設定可能。
- 本日の打鍵数が目標値に到達した瞬間に、`notify-rust` を通じて Windows ネイティブのトースト通知でお祝いを発行。
- 同日内の二重通知を防止し、午前0時のロールオーバー時に通知済みフラグを自動リセット。

### 2.6 カラーテーマ切り替え
- `egui::Visuals` と連動し、以下3つのテーマモードを自由に切り替え可能:
  - `System`: OS のダーク/ライト設定に自動追従
  - `Dark`: コントラストの高いモダンダークテーマ
  - `Light`: 視認性に優れたクリーンライトテーマ

### 2.7 Windows スタートアップ自動起動登録
- `winreg` クレートにより、`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` への登録/解除を設定画面からワンクリックで制御。

### 2.8 CSV エクスポート
- 本日・昨日・累計のサマリー、直近24時間の時間帯別打鍵数、主要キー別ランキング、マウスボタン別統計をまとめた CSV ファイルをワンクリックで同フォルダへ出力。

### 2.9 旧データ自動インポート
- Borland C++ 5.5 製旧ソフト「タイプ数カウンター (typect.exe)」の固定長バイナリ `data`（打鍵）および `data2`（クリック）の先頭28バイトヘッダを自動解析し、累計記録を初回起動時に引き継ぎます。

### 2.10 日付ロールオーバー
- 午前0時の日付切り替わり時に、本日のデータ（打鍵数、クリック数、マウス移動距離）を昨日へスライドし、本日データをゼロクリアして目標通知フラグをリセットします。

## 3. UI 画面構成

1. **ヘッダーパネル (`TopBottomPanel::top`)**:
   - アプリタイトル: `⌨ TypeCT (タイプ数カウンター)`
   - ショートカットボタン:
     - `📊 CSV出力`: CSV ファイルを即時エクスポート
     - `🌙 / ☀️ / 💻`: カラーテーマ切り替え
     - `💾 保存`: 即座に JSON ファイルへ手動保存
     - `📥 トレイに格納`: ウィンドウを非表示にしてタスクトレイへ退避
     - `❌ 終了`: データを保存してアプリを完全終了
   - **ナビゲーションタブ**:
     - `📊 ダッシュボード` / `⌨ キーボードヒートマップ` / `⚙ 設定`
2. **中央メインパネル (`CentralPanel`)**:
   - **ダッシュボードタブ**:
     - サマリーカード4枚（打鍵数、クリック数、マウス移動距離、目標達成率）
     - 本日の目標達成度プログレスバー
     - 直近24時間の時間帯別打鍵数グラフ (`egui_plot::BarChart`)
     - 主要キー別打鍵数ランキング Top 12 (進捗バー付き)
     - 直近の日別サマリー履歴テーブル（直近14日間のキー数・クリック数・移動距離）
   - **キーボードヒートマップタブ**:
     - QWERTY 配列グラデーションヒートマップ
   - **設定タブ**:
     - Windows スタートアップ登録チェックボックス
     - 1日の目標打鍵数スライダー (1,000 〜 50,000 打)
     - カラーテーマ選択
     - CSV 出力実行ボタン
3. **ステータスバー (`TopBottomPanel::bottom`)**:
   - 計測状態ステータスおよび JSON 保存先フルパスを表示

## 4. データ永続化仕様 (`typect.json`)

| フィールド名                 | 型                              | 説明                                               |
| :--------------------------- | :------------------------------ | :------------------------------------------------- |
| `total_keys`                 | `u64`                           | 累計総打鍵数                                       |
| `today_keys`                 | `u64`                           | 本日の打鍵数                                       |
| `yesterday_keys`             | `u64`                           | 昨日の打鍵数                                       |
| `total_clicks`               | `u64`                           | 累計マウスクリック数                               |
| `today_clicks`               | `u64`                           | 本日のマウスクリック数                             |
| `yesterday_clicks`           | `u64`                           | 昨日のマウスクリック数                             |
| `total_mouse_distance_m`     | `f64`                           | 累計マウス移動距離（メートル）                     |
| `today_mouse_distance_m`     | `f64`                           | 本日のマウス移動距離（メートル）                   |
| `yesterday_mouse_distance_m` | `f64`                           | 昨日のマウス移動距離（メートル）                   |
| `days_recorded`              | `u32`                           | 記録日数（通算日数）                               |
| `last_date`                  | `String`                        | 最終記録日付 (`YYYY-MM-DD`)                        |
| `hourly_keys`                | `[u32; 24]`                     | 直近24時間の時間帯別打鍵数                         |
| `key_counts`                 | `HashMap<String,u64>`           | キー種別ごとの打鍵数マップ                         |
| `mouse_counts`               | `HashMap<String,u64>`           | マウスボタン種別ごとのクリック数マップ             |
| `daily_goal_keys`            | `u64`                           | 1日の目標打鍵数（既定値: 10,000）                  |
| `goal_notified`              | `bool`                          | 本日の目標達成通知済みフラグ                       |
| `theme`                      | `ThemeMode`                     | カラーテーマ (`System`, `Dark`, `Light`)           |
| `auto_start`                 | `bool`                          | Windows スタートアップ登録設定                     |
| `daily_history`              | `BTreeMap<String,DailySummary>` | 過去の日毎集計サマリー台帳（プライバシー保護仕様） |
| `legacy_imported`            | `bool`                          | 旧バージョンデータ引き継ぎ完了フラグ               |
