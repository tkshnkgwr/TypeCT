## [0.2.0] - 2026-09-15

### 🚀 新機能 (TODO項目の大幅統合)

- **マウス移動距離計測**:
  - `rdev::MouseMove` イベントを捕捉し、標準画面 DPI (96 DPI) を基準としたメートル / キロメートル換算移動距離のリアルタイム積算・表示・保存に対応。
  - 本日、昨日、累計のマウス移動距離をサマリーカードに可視化。
- **キーボードヒートマップタブ**:
  - QWERTY キー配列ビジュアル画面を新設。
  - 最多打鍵キーに対する比率に応じた 4 段階ヒートマップグラデーション色（青 → シアン → 緑 → 黄 → 赤）でのキー別打鍵分布レンダリング。
  - 各キーにホバーすることで打鍵数と最高頻度比率を表示。
- **目標打鍵数達成トースト通知**:
  - `notify-rust` による Windows ネイティブトースト通知を統合。
  - 1日の目標打鍵数（既定: 10,000打、スライダーで変更可能）に到達した瞬間にデスクトップ通知でお祝い。
  - 1日1回の通知制御および日付ロールオーバー時の自動リセット。
- **ダーク / ライト / システムテーマ切替**:
  - `egui::Visuals` と連動し、ワンクリックでテーマ（💻 システム追従 / 🌙 ダーク / ☀️ ライト）を切り替え、設定を自動保存。
- **Windows スタートアップ自動起動登録**:
  - `winreg` を導入し、設定画面のチェックボックスから `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` への登録/解除を安全に制御。
- **CSV エクスポート機能**:
  - ヘッダーボタンまたは設定タブからワンクリックで、サマリー、直近24時間時間帯別打鍵数、主要キーランキング、マウスボタン別統計、日毎サマリー履歴をまとめた CSV ファイル (`typect_export_YYYYMMDD_HHMMSS.csv`) を出力。
- **日毎サマリー台帳 (daily_history) 永続化 & 直近履歴表示**:
  - キーロガー化を完全に防止（文字ごとの詳細内訳は昨日・今日のみに限定）した上で、日毎の数値合計（打鍵総数・クリック総数・移動距離）を永続台帳として自動保存。
  - ダッシュボード上に「📅 日別サマリー履歴（直近14日間）」テーブルを追加し、日々の活動推移を一目で振り返ることが可能に。
- **3 タブ UI 構成**:
  - 「📊 ダッシュボード」「⌨ キーボードヒートマップ」「⚙ 設定」のタブ切り替えナビゲーションを導入。

## [0.1.0] - 2026-09-15

### 🎉 初期リリース (モダン刷新版)

- **完全フルスクラッチ再構築**:
  - かつての Borland C++ 5.5 版「タイプ数カウンター (typect.exe)」を、Windows 11 (64bit) 向けに Rust 2021 + `egui` で全面再設計。
- **二重起動防止**:
  - Windows Named Mutex (`single-instance`) による多重起動防止機構の実装。
- **日本語文字化け（豆腐化: □）防止**:
  - Windows 標準の日本語フォント（游ゴシック、メイリオ、MSゴシック）の自動探索・優先ロード。
- **低遅延グローバル入力フック**:
  - `rdev` による独立監視スレッドでの非同期入力捕捉（タイピング遅延ゼロ保証）。
- **プライバシー保護**:
  - 文字列やパスワードの記録を行わず、キーコード別カウンター加算のみを行う安全設計。
- **旧データ自動移行**:
  - 旧 `data`（打鍵）および `data2`（クリック）固定長バイナリからの初回自動インポート機能。
- **モダンUI & ダッシュボード**:
  - `egui` による統計サマリーカード表示（本日、昨日、トータル、記録日数、1日平均）。
  - `egui_plot::BarChart` による直近24時間の時間帯別打鍵数グラフ。
  - 主要キー別打鍵ランキング Top 12 (プログレスバー付き)。
- **タスクトレイ常駐 & 動的ツールチップ**:
  - 最小化・閉じる操作時のタスクトレイ格納。
  - トレイホバー時の打鍵数・クリック数リアルタイム動的表示。
- **省電力設計**:
  - アイドル時・バックグラウンド時の待機時 CPU 使用率 0% を維持。
- **リリースバイナリ最適化**:
  - `opt-level = "z"`, LTO, シンボル削除による極小サイズ単一実行ファイル生成。
- **品質管理 & テスト体系**:
  - 包括的 RustDoc コメントの整備。
  - GitHub Actions CI / Release パイプラインの構築。
