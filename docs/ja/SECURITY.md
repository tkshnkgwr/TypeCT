# TypeCT セキュリティ & プライバシー方針 (SECURITY)

本書は、`TypeCT` におけるセキュリティ方針、データプライバシー保護設計、および「キーロガーではないことの証明」について定めた文書です。

---

## 1. 基本方針: 完全なプライバシー保護とローカル完結

`TypeCT` は、ユーザーのタイピング量やマウスクリック量を可視化して作業モチベーションや腱鞘炎予防、日々の生産性管理に役立てるための純粋な計測ツールです。

いかなる場合においても、ユーザーが入力した個人情報、機密情報、入力テキストを不正に窃取・蓄積することはありません。

---

## 2. キーロガー非搭載の設計的証明

本アプリは、アーキテクチャの根本からキーロガーとなり得ない設計（Security by Design）を採用しています。

1. **文字列・テキストの非保持**:
   - `src/input.rs` の `map_rdev_key` 関数において、押下されたキーは即座に固定の識別文字列（例: `"A"`, `"Shift"`, `"Enter"`）へと独立変換されます。
   - 入力された連続する文字列（単語、文章、パスワード等）をバッファに蓄積するデータ構造はコード内に一切存在しません。
2. **集計カウンターのみの保持**:
   - データモデル (`src/model.rs`) が保持するのは、「どのキーが何回押されたか」という純粋な整数カウンター (`HashMap<String, u64>`) および「時間帯別の総打鍵数」のみです。
3. **ネットワーク通信の完全排除 (Air-Gapped)**:
   - 本アプリケーションは外部ネットワークへの通信機能を一切持っていません（HTTPクライアントやソケット通信等のクレートは一切リンクされていません）。
   - すべてのデータはローカルマシンの `typect.json` にのみ保存され、外部に送信されることは物理的に不可能です。
4. **完全なオープンソース**:
   - ソースコードは 100% 公開されており、ユーザー自身がビルドして挙動を検証可能です。
