# TypeCT ユーザーガイド (USER_GUIDE)

本書は、打鍵・マウスクリック数計測アプリ「TypeCT」の導入方法、日常の使い方、タスクトレイの操作、および旧データ移行手順を分かりやすく説明した操作説明書です。

---

## 1. インストール & 起動

### 1.1 インストール
`TypeCT` は単一の実行ファイル (`typect.exe`) だけで動作します。インストーラーは不要です。
お好きなフォルダー（例: `%USERPROFILE%\Tools\TypeCT\` など）に `typect.exe` を配置してください。

### 1.2 起動
`typect.exe` をダブルクリックして起動します。

> [!NOTE]
> `TypeCT` は二重起動防止機能を備えています。既に起動している状態で再度実行した場合は、何も起きずに静かに終了します。画面が表示されない場合はタスクトレイ（画面右下の通知領域）をご確認ください。

---

## 2. 画面の見方

起動すると以下のメインウィンドウが表示されます。

```
+-------------------------------------------------------------------------+
| ⌨ TypeCT (タイプ数カウンター)               [💾 保存] [📥 トレイに格納] [❌ 終了] |
+-------------------------------------------------------------------------+
| [本日の打鍵数]      [昨日の実績]         [累計トータル]       [記録日数/平均]      |
|  12,345 打         10,200 打           1,234,567 打       120 日間           |
|  クリック: 3,456回  クリック: 2,800回    クリック: 450,000回 平均: 10,288 打/日 |
+-------------------------------------------------------------------------+
| 直近24時間の時間帯別打鍵数                                               |
| [  ▂▃▅▆▇█▇▆▅▃▂   ] (時間ごとの棒グラフ)                                  |
+-------------------------------------------------------------------------+
| キー別打鍵数ランキング (Top 12)                                         |
|  1. Space      [████████████████████████] 2,450 回                      |
|  2. E          [████████████████        ] 1,820 回                      |
|  3. Backspace  [████████████            ] 1,210 回                      |
|  ...                                                                    |
+-------------------------------------------------------------------------+
| ステータス: 計測中（常駐中）          保存先: %USERPROFILE%\...\typect.json |
+-------------------------------------------------------------------------+
```

### 2.1 ヘッダーボタン
- **💾 保存**: 現在の集計状態を即座に `typect.json` へ書き出します。
- **📥 トレイに格納**: ウィンドウを隠し、画面右下のタスクトレイへ格納します（計測は継続されます）。
- **❌ 終了**: データを保存した上で、アプリを安全に終了します。

---

## 3. タスクトレイでの利用

作業中に邪魔にならないよう、ウィンドウを最小化したり「✕」ボタンを押すと、自動的にタスクトレイに格納されます。

- **ウィンドウの再表示**:
  - タスクトレイの「T」アイコンを**左クリック**すると、ウィンドウが画面中央に再表示されます。
- **打鍵状況の簡易確認 (動的ツールチップ)**:
  - タスクトレイのアイコンにマウスカーソルを合わせると、以下のように本日の打鍵数とクリック数がリアルタイムで表示されます。
  ```text
  TypeCT - 今日: 6,183打 / 4,952クリック
  ```

## 4. 旧「タイプ数カウンター (typect.exe)」からのデータ引き継ぎ

旧バージョンのデータをお持ちの方は、以下の手順で簡単に累計記録を引き継ぐことができます。

1. 新しい `typect.exe` と同じフォルダーに、旧環境の記録ファイル `data`（打鍵）および `data2`（クリック）を配置します。
2. `typect.exe` を起動します。
3. 初回起動時に過去の累計打鍵数、累計クリック数、記録日数、昨日・本日の実績が自動で読み込まれます。
4. 引き継ぎが完了すると、画面内に緑色の文字で「※ 旧 typect (data / data2) からの累計データを引き継ぎ済み」と表示されます。
5. 以降はモダンな `typect.json` に最新の集計データが記録されます。

---

## 5. 自動保存の仕組み

データは以下のタイミングで自動的に保存されます。
- 5分ごとの定期自動保存
- ウィンドウを閉じてタスクトレイに格納した瞬間
- 「❌ 終了」ボタンを押して終了する瞬間
- Windows シャットダウン等でアプリが終了する瞬間

万が一の急な停電や再起動でも、直前までのデータが確実に保護されます。
