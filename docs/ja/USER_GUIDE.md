# TypeCT ユーザーガイド (USER_GUIDE)

本書は、打鍵・マウスクリック数・マウス移動距離計測アプリ「TypeCT」の導入方法、日常の使い方、新機能（ヒートマップ、目標通知、テーマ切替、スタートアップ登録、CSV出力）を分かりやすく説明した操作説明書です。

---

## 1. インストール & 起動

### 1.1 インストール
`TypeCT` は単一の実行ファイル (`typect.exe`) だけで動作します。インストーラーは不要です。
お好きなフォルダー（例: `%USERPROFILE%\Tools\TypeCT\` など）に `typect.exe` を配置してください。

### 1.2 起動
`typect.exe` をダブルクリックして起動します。
多重起動防止機能により、既に起動している場合は静かに終了します。画面が見当たらない場合はタスクトレイをご確認ください。

---

## 2. 画面とタブの使い方

画面上部のタブセレクターで 3 つの画面を切り替えることができます。

### 2.1 📊 ダッシュボード
- **サマリーカード**:
  - 本日の打鍵数、クリック数、**マウス移動距離**（例: `350.2 m` / `1.45 km`）
  - 昨日の実績
  - 累計トータル
  - 記録日数、1日平均打鍵数、目標達成率
- **目標達成度プログレスバー**:
  - 1日の目標打鍵数に対する進捗度を視覚的に表示。
- **直近24時間の時間帯別打鍵数棒グラフ**:
  - 時間帯ごとの作業ピークを可視化。
- **キー別打鍵数ランキング**:
  - 最も打鍵数の多い Top 12 キーをグラフ表示。
- **日別サマリー履歴（直近14日間）**:
  - 過去の日付ごとの打鍵総数・クリック数・マウス移動距離を一覧表示。
  - ※ **プライバシー完全保護**: 文字ごとの詳細内訳は「今日」と「昨日」のみに限定され、日毎履歴は総数のみを記録するため、キーロガー化することなく安全に蓄積されます。


### 2.2 ⌨ キーボードヒートマップ
- QWERTY 配列キーボード上に、自分の打鍵頻度分布をヒートマップで視覚化します。
- よく叩くキーは**赤・黄**などの暖色系、あまり叩かないキーは**青・シアン**などの寒色系で塗りつぶされます。
- キーの上にマウスを乗せると、具体的な打鍵回数と最高頻度比率が表示されます。

### 2.3 ⚙ 設定
- **Windows スタートアップ自動起動**:
  - チェックを入れるだけで、Windows ログオン時に TypeCT が自動的にバックグラウンド起動します。
- **1日の目標打鍵数スライダー**:
  - 1,000〜50,000 打の間で目標を設定可能。目標達成時に Windows トースト通知でお祝いされます。
- **カラーテーマ切替**:
  - `💻 システム設定` / `🌙 ダーク` / `☀️ ライト` をワンクリックで選択できます。
- **CSV ファイル出力**:
  - ボタンを押すと、現在の集計統計（日別・時間帯別・キー別・マウス別）を CSV ファイルへ保存します。

---

## 3. ヘッダーショートカット

- **📊 CSV出力**: どのタブからでも即座に CSV ファイルを出力できます。
- **🌙 / ☀️ / 💻**: カラーテーマをすばやくローテーション切り替えできます。
- **💾 保存**: 即座に `typect.json` へデータを書き込みます。
- **📥 トレイに格納**: ウィンドウを非表示にしてタスクトレイへ退避します。
- **❌ 終了**: データを保存して安全にアプリを終了します。

---

## 4. タスクトレイでの利用

ウィンドウを最小化したり「✕」ボタンを押すと、自動的にタスクトレイに格納されます。

- **ウィンドウの再表示**:
  - タスクトレイの「T」アイコンを**左クリック**すると、ウィンドウが再表示されます。
- **動的ツールチップ**:
  - トレイアイコンにマウスを合わせると、本日の打鍵数・クリック数・マウス移動距離がリアルタイムで表示されます:
  ```text
  TypeCT - 今日: 6,183打 / 4,952クリック / 450.2 m
  ```

---

## 5. 旧「タイプ数カウンター」からのデータ引き継ぎ

1. 新しい `typect.exe` と同じフォルダーに、旧環境の記録ファイル `data`（打鍵）および `data2`（クリック）を配置します。
2. `typect.exe` を起動します。
3. 初回起動時に過去の累計記録が自動的に `typect.json` に引き継がれます。
